# Crossroads and Starlight policies

Public Terms of Service and Privacy Policy for the Discord game.

## Publish

1. Create a public GitHub repository named `crossroads-and-starlight-policies`.
2. Upload all files in this folder to the repository root and commit.
3. Open Settings → Pages. Under Build and deployment, select Deploy from a branch, then `main` and `/ (root)`. Save.
4. Wait for GitHub to display the published site URL.

Developer Portal URLs will be:

- `https://YOUR-USERNAME.github.io/crossroads-and-starlight-policies/terms.html`
- `https://YOUR-USERNAME.github.io/crossroads-and-starlight-policies/privacy.html`

Use the username shown by your GitHub account. These URLs become valid after Pages deploys.
