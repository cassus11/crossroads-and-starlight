Privacy Policy

This policy explains how the Crossroads and Starlight application handles information. Discord handles its own platform data under Discord’s Privacy Policy.

Information processed

  • Your Discord user ID, linked to an automatically generated internal game account.
  • The Discord server ID, used to maintain separate campaign saves for each server.
  • Commands and options you submit to the app, processed to perform game actions.
  • Saved game data, including character names, character selections and descriptions, statistics, inventory, quests, discoveries, and other persistent game state.
  • Temporary game sessions, event queues, and social interactions such as party messages and in-game speech.
  • Operational error logs, which may include technical identifiers or submitted content when needed to diagnose a failure.

The app does not intentionally collect your email address, real name, Discord password, payment information, or ordinary channel-message history. It uses slash-command interactions and does not request Discord’s Message Content intent. It does not store a general transcript of every command; resulting game state can persist.

Use and sharing

Information is used to identify players, save progress, operate multiplayer features, prevent abuse, and diagnose problems. Game replies are currently private to the interacting player, but social actions and game events can be delivered to other participating players. Authorized operators with access to the host or backups may access stored data for operation and support. Discord processes interactions and responses. Hosting and infrastructure providers may process data needed to provide their services. Data may also be disclosed where required by law. The operator does not sell player data, use it for advertising, or send it to AI services for training or content generation in the current application.

Storage and retention

Campaign data is stored in SQLite databases on the operator’s host. Saved progress is retained while the campaign remains available and until deletion is requested or the operator removes it. Session queues are bounded and temporary; they disappear when consumed or the process restarts. Operational logs and backups may persist separately. Removing the bot from a server or deleting a character does not automatically delete all account records or backups. No specific backup-expiry schedule is currently guaranteed; a deletion request includes review of retained copies and any retention required by law.

Your choices and deletion

You may stop using the application at any time. Request access, correction, or deletion through the contact method below. Identify the Discord user ID and affected server; the operator may ask you to verify control of that account. Do not send your Discord password or bot tokens. Requests will be handled within applicable legal requirements. Deletion can remove saved progress permanently. Messages already delivered through Discord are subject to Discord’s own controls and retention.

Security and children

The operator limits data access and protects credentials, but no system can guarantee absolute security. The app is intended only for users eligible to use Discord under its age rules. If information from an ineligible child is identified, contact the operator to request its removal.

Changes

This page will be updated when data practices change. The effective date above identifies the current version.

Delete your game data directly

Run /crossroads delete-my-data in Discord to read the confirmation notice. Run it again with confirm: True to authorize permanent deletion. No email address is required. This deletes your Discord-to-account link, internal account, characters, inventory, quests, discoveries, character-scoped state, and private session queue across all campaigns stored by this bot installation, including campaigns not currently loaded.

The command does not create a new account. Using another game command afterward starts a new empty account. Other players’ saves and shared world outcomes remain. Previously delivered Discord messages are governed by Discord’s controls. Separate operator logs and backups are not erased by this command; ask the operator through your server administrator if you need help with retained copies. Restoring an older backup may restore old records, so the operator must reapply deletion requests before using a restored backup.

Support and privacy requests

For saved-account deletion, use /crossroads delete-my-data confirm: True. For access, correction, deletion errors, or other privacy questions, contact the application operator through the Discord server where you use Crossroads and Starlight. Ask the server owner or administrator to connect you with the bot operator. No dedicated public email address is provided.
